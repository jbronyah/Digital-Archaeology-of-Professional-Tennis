# Data sources and attribution

- **Match Charting Project**, Jeff Sackmann / Tennis Abstract and volunteer contributors. Source [repository](https://github.com/JeffSackmann/tennis_MatchChartingProject/tree/1813a1309b7ed7ebf1c7e884b32bf675d00e4edf) and [project and contributor credits](https://www.tennisabstract.com/charting/meta.html).
- **Tour match archive**, compiled by Jeff Sackmann and preserved by [Aneeshers](https://github.com/Aneeshers/tennis-sackmann-archive). The local copy did not have an independently recorded Git commit. The exact annual-file inputs are identified by SHA-256 in `sources.json`.

The input extracts and data-derived outputs are distributed under [CC BY-NC-SA 4.0](https://creativecommons.org/licenses/by-nc-sa/4.0/). This package changes the source data by restricting it to main-draw singles matches at the four Grand Slams in 1995–2025, projecting point and metadata columns, and compressing those CSVs. Match-level aggregate rows for eligible tournament/date candidates are kept intact to preserve conflict checks. The separate tour archive is represented here by match counts grouped by tour, Slam, and period. The extraction preserves point row order and repeated variants for auditing.

`sources.json` hashes the preserved upstream inputs and `snapshot.json` hashes the bundled extracts. The metadata retains the original player names and charting-credit strings. The [charting guide](https://www.tennisabstract.com/blog/2015/09/23/the-match-charting-project-quick-start-guide/), [rally glossary](https://www.tennisabstract.com/blog/2019/08/17/match-charting-project-rally-stats-glossary/), and [tactics glossary](https://www.tennisabstract.com/blog/2019/08/17/match-charting-project-tactics-stats-glossary/) explain the source notation.
